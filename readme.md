# DreamDo Little Farmer 🌱

> **"Dream it. Grow it. Transform the future."**  
> *Empowering the next generation of farmers through practical learning, creativity, and agricultural innovation.*

DreamDo Little Farmer empowers children, young people, and communities to discover the possibilities of modern agriculture beyond subsistence toil—connecting biological science, technology, creativity, entrepreneurship, and sustainable food systems.

---

## 🚀 Features

- **6 Core Navigation Hubs**:
  - `Home`: National context (NISR indicators), 4-stage inquiry learning preview, commercial product showcase.
  - `Our Approach`: Reimagined agricultural philosophy, 4-stage pedagogy, and child protection compliance framework.
  - `Little Farmer`: 4-week program curriculum, educational enablers, and savings goal simulation.
  - `Products & Services`: Dedicated commercial storefront (HDPE Cone Garden, Seedlings & Plant Multiplication, Garden Setup Advisory, Playbook, YouTube Grower Hub).
  - `For Schools & Communities`: Institutional pathways (Schools, Corporate CSR / ESG, Community Hubs / NGOs).
  - `Stories & Resources`: Practical grower YouTube tutorial series and student innovation showcases.
- **Full Bilingual Localization**: Instant English (`EN`) and Kinyarwanda (`RW`) toggling across all 6 pages.
- **Child Protection Safeguard**: Strict educational positioning—children explore value chains and budgeting as supervised simulations; all commercial operations are adult-managed.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/) (HashRouter configured for seamless GitHub Pages deep linking and zero-404 refreshes)

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates production-ready static assets in the `dist/` directory.

---

## 🌐 GitHub Pages Deployment

This repository includes an automated GitHub Actions workflow (`.github/workflows/deploy.yml`):
1. In your GitHub repository, go to **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, select **GitHub Actions**.
3. Every `git push` to the `main` branch will automatically build and deploy the site to GitHub Pages!
